Nécessite le pilote ODBC HFSQL 64 bits (PC SOFT) installé sur le serveur de l'application. Port HFSQL par défaut : 4900. Le pilote est détecté automatiquement ; « DRIVER=… » permet d'en imposer un autre (anciennes versions : « HyperFileSQL »). Ajoutez « Password=… » si les fichiers HFSQL sont protégés par mot de passe.
Si le test reste bloqué : déclarez une source dans l'administrateur ODBC 64 bits (onglet DSN système) puis indiquez ici DSN=nom_de_la_source.

La base est créée avec l'utilisateur ci-dessus comme propriétaire (droit CREATEDB nécessaire). Les tables y seront créées automatiquement par les jobs.

Le mot de passe est chiffré dans la base interne. Pour une source, un utilisateur en lecture seule suffit.

Dans Google Sheets : Partager → Accès général : Tous les utilisateurs disposant du lien (Lecteur). Simple, mais toute personne ayant le lien peut lire le classeur.

1. Dans Google Cloud Console : créez un projet, activez l'API Google Drive.

2. IAM → Comptes de service : créez un compte, puis Clés → Ajouter une clé → JSON ; collez ici le contenu du fichier.

3. Partagez le classeur (Lecteur) avec l'adresse e-mail du compte de service{% if sa_email %} : {{ sa_email }}{% endif %}.

Chaque onglet devient une table : la première ligne contient les en-têtes (convertis en noms de colonnes simples : « Date d'arrivée » → date_d_arrivee).

1. Dans Smartsheet : Compte → Applications et intégrations → Accès à l'API → « Générer un nouveau jeton d'accès » ; collez-le ici (il est chiffré dans la base interne). Le compte du jeton doit avoir accès aux feuilles (lecteur suffit).

2. Identifiant d'une feuille : Fichier → Propriétés → ID de la feuille. Vous pouvez aussi saisir son nom exact. « Tester la connexion » sans feuille liste les feuilles accessibles avec leur identifiant.

3. Chaque feuille devient une table : en-têtes de colonnes simplifiés (« Date de départ » → date_de_depart), dates et cases à cocher typées, plus une colonne row_id (identifiant stable de la ligne, à utiliser comme clé).
